# Subux Default Color Theme

Subux의 기본 색상 테마는 무채색 배경과 파스텔 강조색을 사용하며, 라이트·다크 모드를 지원한다.

| 용도 | 라이트 | 다크 |
| --- | --- | --- |
| 페이지 배경 | `#fafafa` | `#171717` |
| 기본 글자 | `#1f1f1f` | `#ececec` |
| 보조 글자 | `#666666` | `#a3a3a3` |
| 기본 강조색 | `#c2e7ff` | `#c2e7ff` |
| 보조 강조색 | `#ffdac2` | `#ffdac2` |

파스텔 강조색은 배경에 사용하며, 그 위의 글자색은 두 모드 모두 `#1f1f1f`다.

색상 값은 [tokens.json](tokens.json)에 정의되어 있다.
